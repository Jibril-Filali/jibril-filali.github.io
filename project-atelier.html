> L'Atelier du Détail

Boutique e-commerce fictive d'accessoires féminins. De la page d'accueil jusqu'à la confirmation de commande, tout est là — sans base de données. Les produits, le panier, le thème et les données admin vivent entièrement dans le localStorage du navigateur. Le back-end Spring Boot sert uniquement les fichiers statiques.

HTMLCSSJavaScriptJavaSpring Boot
root@projects:~$ cat ./atelier/pourquoi.txt

Une amie en formation marketing devait créer une marque fictive pour son cours — études de marché, positionnement, stratégie de comm'. Il y avait une option pour aller plus loin avec un site ou une maquette, et elle m'a demandé de l'aider. J'ai préparé un cahier des charges complet, elle l'a rempli avec toutes les specs de sa marque, et je l'ai codé à partir de là.

C'est le projet le plus long que j'aie fait — deux à trois mois de travail. La première fois que je construisais quelque chose d'aussi complet de A à Z : catalogue, panier, caisse, espace admin, gestion du thème... Et aussi la première fois que j'utilisais Spring Boot pour servir une app statique.

$ Fonctionnalités

  • Catalogue avec filtres catégorie, recherche texte et tri prix/nom
  • Panier persistant, caisse simulée, confirmation de commande
  • Page favoris — toggle coeur sur chaque produit
  • Admin CRUD produits (upload image, compression canvas)
  • Personnalisation thème en direct (couleurs + police)
  • Authentification SHA-256 côté client (crypto.subtle)

$ Architecture

  • Spring Boot 3.2.4 / Java 17 — sert les statiques
  • Zéro appel API — tout en localStorage
  • Paiement simulé (Stripe factice)
  • Images produit en base64 (max 900px, qualité 78%)
  • Cookie RGPD — bandeau accept/refuse
root@projects:~$ cat ./atelier/js/admin.js
admin.js — authentification SHA-256 
// Mot de passe jamais stocké en clair —
// on hash la saisie et on compare au hash connu
const HASH_ATTENDU = '...'; // sha256('atelier2026')

async function verifierMotDePasse(input) {
  const encoded = new TextEncoder().encode(input);
  const buffer  = await crypto.subtle.digest('SHA-256', encoded);
  const hash    = Array.from(new Uint8Array(buffer))
    .map(b => b.toString(16).padStart(2, '0')).join('');
  return hash === HASH_ATTENDU;
}

// Connexion — stockée en sessionStorage (pas localStorage)
verifierMotDePasse(input).then(ok => {
  if (ok) sessionStorage.setItem('admin_connecte', '1');
  else   afficherErreur('Mot de passe incorrect');
});
Projet école — le paiement est 100% simulé, aucune transaction réelle. L'authentification SHA-256 est suffisante pour un contexte demo, pas pour une vraie prod.
