> SetupClaude

Guide en français pour installer et configurer Claude Code. La documentation officielle n'est pas toujours simple à suivre, j'ai voulu faire quelque chose de direct. Un terminal IA est intégré dans la page : tu tapes une question, Claude Haiku répond via l'API Anthropic.

HTMLCSSJavaScriptAPI Anthropic
root@projects:~$ cat ./setupclaude/pourquoi.txt

En regardant des vidéos YouTube et en traînant sur différents forums et réseaux, j'ai découvert ce que Claude Code pouvait vraiment faire. Pas juste un chatbot, un vrai outil de travail qui change la façon de coder. J'y crois vraiment pour l'avenir. Le problème, c'est que beaucoup de gens autour de moi soit ignorent ça complètement, soit ont peur de l'IA sans vraiment savoir l'utiliser.

SetupClaude, c'est ma réponse à ça. Une ressource en français, directe, pour que n'importe quel étudiant puisse démarrer avec Claude Code en moins de 5 minutes sans se perdre dans la doc officielle. Et le terminal IA dans la page, c'est pour montrer concrètement ce que l'API peut faire. Pas juste en parler.

// Appel API Anthropic — Claude Haiku en temps réel
async function sendToClaude(prompt) {
  const res = await fetch('https://api.anthropic.com/v1/messages', {
    method: 'POST',
    headers: {
      'x-api-key':           apiKey,
      'anthropic-version':   '2023-06-01',
      'content-type':        'application/json'
    },
    body: JSON.stringify({
      model:      'claude-haiku-4-5-20251001',
      max_tokens: 512,
      messages:   [{ role: 'user', content: prompt }]
    })
  });
  const data = await res.json();
  return data.content[0].text;
}
